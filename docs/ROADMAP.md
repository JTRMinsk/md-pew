# md-pew Roadmap

## Now

- Keep the app as a dependable single-file Markdown editor and previewer.
- Improve the local editing experience before introducing a build system.

## Next

- Add better Markdown coverage through a dedicated parser when the project moves beyond one file.
- Add syntax highlighting for fenced code blocks.
- Add preview themes.
- Add find/replace.
- Add recent files once a desktop wrapper exists.

## Later

- Package native apps with Tauri for Windows and macOS.
- Add file associations for `.md` files.
- Add autosave and recovery.
- Add optional export to PDF.
- Add a polished app icon and installer metadata.

## Parking Lot

- Side-by-side scroll sync improvements for very long documents.
- Outline sidebar based on headings.
- Image paste support.
- Mermaid diagram rendering.
